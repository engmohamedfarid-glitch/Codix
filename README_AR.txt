CODI.X — تعديل الصورتين فقط
================================
- كلمة CODI.X أعلى الموقع وأسفله رجعت كتابة كما كانت، في جميع الصفحات.
- الصورة الكبيرة الأولى في Home: assets/home-hero.png
- الصورة الكبيرة الثانية في Home: assets/home-team.png
- لتغيير أي صورة: احذف الصورة القديمة، وضع صورتك الجديدة بنفس اسم الملف وبصيغة PNG.
- لا تحتاج لتعديل JavaScript أو HTML لتغيير الصور.
- باقي الصفحات والأقسام والكورسات والهيكل كما كانت في النسخة السابقة.
- افتح index.html باستخدام Live Server من VS Code.
- لوحة admin.html تجريبية وتخزن البيانات محليًا فقط.
